AI 编码工具测评向导

结果质量 · 过程能力 · token 成本 · 时间成本 —— 五步完成一次对比测评

1选择任务
2生成测试环境
3运行任务
4确认与采集
5生成报告

第一步 · 选择测试任务

任务按复杂度分为三档：easy（小型修复）/ medium（功能实现）/ hard（SPEC 驱动的多文件应用）。所有候选工具将跑同一任务。

第二步 · 登记参评工具，生成测试目录与提示词

为每个参评的编码工具登记 agent + 模型 + 参数。点击「生成测试环境」后，每个候选会得到独立的 run 目录（干净工作区）和任务提示词。

Agent模型名上下文窗口思考强度

第三步 · 打开各编码工具运行任务

按下方指引逐个启动编码工具：cd 进对应 work 目录 → 设置模型与参数（须与登记一致）→ 粘贴提示词开始任务 → 任务完成后正常结束会话。

第四步 · 确认全部跑完，采集日志并客观检查

确认所有候选任务均已完成后点击「开始采集」。系统会自动：定位日志 → 归一化 token/耗时 → 运行 verifier 客观检查 → 提取过程信号。

第五步 · 生成对比测评报告

将对每个 run 进行 LLM 盲评（需先配置 config/judge.json），生成对比分析正文与 HTML 报告。权重可调（默认 R45 结果 / P30 过程 / T15 token / D10 时间）。
